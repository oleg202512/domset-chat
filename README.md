# ДомСеть: Техподдержка

Учебное веб-приложение на FastAPI, HTML, CSS и Vanilla JS. Приложение ищет пять релевантных фрагментов в базе знаний с помощью `text-embedding-3-small`, а затем формирует ответ моделью `gpt-5.6-luna` через OpenAI-совместимый API учебной платформы.

## Запуск

1. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Запустите приложение:

   ```powershell
   python -m uvicorn app.main:app --reload
   ```

3. Откройте в браузере `http://127.0.0.1:8000`.
4. Нажмите «Настройки», вставьте API-ключ учебной платформы и сохраните его.

Ключ не записывается в исходный код и передаётся бэкенду заголовком `X-API-Key`. В учебном режиме он хранится в `localStorage`, как предусмотрено заданием. История диалога хранится в памяти бэкенда и очищается кнопкой «Новый чат».

## Структура

- `app/main.py` — FastAPI-маршруты, сессии и обработка ошибок.
- `app/llm_service.py` — отдельный сервис вызова языковой модели.
- `app/rag.py` — разбиение базы знаний, embeddings и cosine similarity.
- `База_знаний_ДомСеть.txt` — исходная база знаний.
- `static/` — русскоязычный интерфейс приложения.
